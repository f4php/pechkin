# RichTextSuperscript

Source: https://core.telegram.org/bots/api#richtextsuperscript

A superscript text.

| Field | Type | Description |
| --- | --- | --- |
| type | String | Type of the rich text, always “superscript” |
| text | [RichText](https://core.telegram.org/bots/api#richtext) | The text |
