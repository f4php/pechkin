# RichMessage

Source: https://core.telegram.org/bots/api#richmessage

Rich formatted message.

| Field | Type | Description |
| --- | --- | --- |
| blocks | Array of [RichBlock](https://core.telegram.org/bots/api#richblock) | Content of the message |
| is_rtl | Boolean | *Optional*. *True*, if the rich message must be shown right-to-left |
